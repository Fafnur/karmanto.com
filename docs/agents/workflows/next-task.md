# Следующая задача

Все пути — от корня репозитория.

1. Прочитай `AGENTS.md`, `docs/progress.md`, описание задачи в `docs/plan.md` и связанные решения.
   Бери задачу, указанную пользователем; иначе — первую `[~]`, затем первую `[ ]` в плане разработки.
   Не принимай пункты проверки владельцем перед выпуском за самостоятельные задачи разработки.
2. Прочитай правила Git и все применимые правила из `AGENTS.md`.
3. Обсуди неочевидные решения до кода. Уже согласованное в беседе или образце повторно не спрашивай.
4. Проверь рабочее дерево, сохрани чужие изменения. Создай отдельную ветку от свежего `main`
   по правилам Git; продолжай существующую ветку задачи, если работа уже начата.
5. Отметь задачу `[~]`, выполни её в пределах плана. Если не хватает обещанных владельцем материалов,
   выполни независимую часть и укажи, что осталось.
6. Выполни проверки из `AGENTS.md`, обнови прогресс и решения. Не отмечай задачу выполненной,
   если обязательные проверки или часть работы остались незавершёнными.
7. Отчитайся о результате, проверках и ограничениях. Коммиты и PR — по правилам Git и указаниям пользователя.
