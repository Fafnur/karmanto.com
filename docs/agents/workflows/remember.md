# Сохранить знание о проекте

Зафиксируй сведения из просьбы пользователя.

Выбери одно подходящее место (не личную память агента):

- правило работы или договорённость для всего проекта → `AGENTS.md`;
- правило для конкретной области кода → соответствующий файл в `docs/agents/rules/` (если создаёшь новый, добавь его область применения и ссылку в `AGENTS.md`);
- продуктовое/архитектурное решение или отклонение от плана → новая запись сверху в `docs/decisions.md` с сегодняшней датой;
- статус задачи → `docs/progress.md`.

Перед записью проверь, нет ли уже похожего пункта — обнови его вместо дубля. Покажи, что и куда записал.
