# karmanto.com — план первой версии сайта

Сайт мобильного приложения **Karmanto** (карточки для запоминания слов, iOS и Android): маркетинговая страница,
юридические документы, поддержка, удаление аккаунта, форма обратной связи. Чистая статика: Angular SSG → свой
сервер (nginx), как у `isomantika.com`.

**Образец — репозиторий `isomantika.com`** (агенту доступен; дальше — «образец»). Сайт Karmanto повторяет его
архитектуру, страницы и бизнес-логику почти один в один: меняются бренд, цвета, шрифт и тексты. Репозиторий новый,
с чистой историей: код образца **не копируется папкой**, а переносится по задачам — сущности Nx создаются
генераторами, содержимое файлов берётся из образца и адаптируется. Решения образца (`docs/decisions.md` образца)
действуют и здесь, если ниже не сказано иначе; повторно их не обсуждаем.

Каждая задача ниже — самостоятельный промпт для кодинг-агента. Выполнять по порядку, по одной. Задачи крупные:
одна задача — одна ветка и один PR, внутри — коммиты по шагам.

## Правила работы

- **Перед выполнением любой задачи — grill me.** Сначала расспроси владельца о неочевидных решениях
  (поведение, UX, тексты, крайние случаи), предложи варианты с рекомендацией; код — только после ответов.
  То, что уже решено в образце и не меняется в этом плане, не спрашивай — переноси.
  Принятые решения — в `docs/decisions.md`.
- **Каждая задача — в отдельной ветке** от свежего `main`: `feature/<номер>-<кратко>` (`feature/1-workspace`),
  исправления — `fix/<кратко>`. В `main` — только через PR после зелёного CI. Перед мёржем ветку ребейзим на свежий
  `main` (`git rebase main`, `git push --force-with-lease`), мёрж — «Create a merge commit».
- Коммиты — `[тип] Кратко в повелительном наклонении` по-английски: `[feat] 2: Theme tokens`, `[fix] …`, `[docs] …`.
- **Nx — только через генераторы** (`yarn nx g @nx/angular:library …`, `yarn nx g @nx/angular:component …`),
  сначала с `--dry-run`. Код из образца переносится в созданные генератором файлы, а не копированием папок
  (`project.json`, пути в `tsconfig.base.json`, теги должны появиться штатно).
- Библиотеки — в `libs/`, приложения — в `apps/`. Импорт — только через алиас `@karmanto/…`.
- Задача готова, когда `yarn check` (lint, test, build, e2e) зелёный; статус — в `docs/progress.md`.
- **`README.md` — витрина на GitHub:** сверху на английском дублирует тексты главной, ниже — раздел для
  разработчиков. Меняются тексты главной — обновлять README в той же задаче.
- Не расширять объём задачи: то, что помечено «Не входит», без явной просьбы не делаем.
- **Юридические тексты (`content/`)** — черновики пишет агент один раз, в задаче 3, по прямой просьбе владельца.
  После этого — как в образце: не править без явной просьбы, даже опечатки (сообщить владельцу).
  Никаких секретов в репозитории.

## Зафиксированные решения

- **Репозиторий:** новый публичный `karmanto.com` на GitHub, создаёт владелец. Настройки — как у образца: только
  «Create a merge commit», удаление веток после мёржа, ruleset `main` (только через PR, обязательная проверка CI,
  без force push).
- **Стек и правила кода — как в образце, без изменений:** Nx, Yarn 4 (Corepack, `nodeLinker: node-modules`),
  Node 24, Angular 22 (standalone, zoneless, `OnPush` по умолчанию, гидрация с `withI18nSupport()`,
  `withIncrementalHydration()`), SSG (`outputMode: "static"`, все роуты `RenderMode.Prerender`), Tailwind 3.4,
  `@tailwindcss/typography` (`target: 'legacy'`), точечные полифилы core-js, `.browserslistrc` образца,
  Signal Forms, CDK — только меню языков и темы, Vitest (приложение — `@angular/build:unit-test`, библиотеки —
  `@nx/vitest` + AnalogJS), Playwright (desktop, tablet 820×1180, Pixel 7), ESLint и Prettier — конфиги образца.
  Соглашения (`$`-сигналы, `host: {}`, `onX`, `is-*`, директивы кнопок, `@Service()`, `inject(LocalStorage)`) —
  из `CLAUDE.md` образца.
- **Имена:** алиас `@karmanto/*`, префикс селекторов `km`, корневой пакет `@karmanto/source`. Ключи
  `localStorage` — `karmanto.consent`, `karmanto.theme`, `km-language-hint-closed`.
- **Языки сайта:** `en` — исходный, в корне; `ru` → `/ru/`, `es` → `/es/`. Без автоперенаправления. Адреса со
  слешем на конце.
- **Ссылки, которые уже использует приложение (менять нельзя):** `/privacy/`, `/terms/`, `/ru/privacy/`,
  `/ru/terms/`, `/es/privacy/`, `/es/terms/` (`lib/core/config/app_links.dart` приложения). После задачи K.1
  в репозитории приложения добавятся `/support/`, `/ru/support/`, `/es/support/`. Всё это закрепляет
  контрактный e2e.
- **Домены:** `karmanto.com` — единственный адрес сайта. `www.karmanto.com`, `karmanto.ru` и `www.karmanto.ru` —
  301 на `https://karmanto.com$request_uri`.
- **Хостинг — как у образца:** тот же сервер `130.49.174.192` (nginx, certbot), папка `/var/www/karmanto.com`,
  деплой из GitHub Actions по rsync той же сборкой, что прошла проверки; свой ключ `karmanto-deploy`.
- **Почта:** `support@karmanto.com` (ImprovMX, как у образца).
- **Бренд:** иконка приложения `docs/logo/karmanto-icon.svg` (из репозитория приложения, «карман с карточкой»)
  **как есть** — в шапке рядом с вордмарком «Karmanto», в фавиконе, иконках и `og.png`. Мини-брендбук.
- **Цвета — палитра приложения «Песочная»** (`docs/palette.md` приложения, источник истины —
  `lib/core/theme/app_colors.dart`): две темы. **Тема по умолчанию — системная**, переключатель в шапке:

  (Čeština, Ελληνικά, Tiếng Việt) не будут собраны из разных шрифтов. Иероглифы, арабский, деванагари и т. п. —
  системный шрифт. Preload — только латиница (и кириллица на `/ru/`), как в образце.
- **Форма:** отступы — сетка 4 px; скругления как в приложении: кнопки и поля 14 px, карточки 18 px,

- **Цена, Pro и лимиты на сайте не упоминаются** — ни «бесплатно», ни «скоро Pro», ни «10 000 слов».
  Pro-функции (нейроозвучка, LLM-подсказки, сток картинок, облако для фото) не описываются.
- **Факты для текстов — из `docs/plan.md` приложения (v1)**, даже если функция ещё не сделана; перед выпуском —
  сверка с приложением (задача 7). Пути меню и подписи кнопок — дословно из `lib/l10n/app_{en,ru,es}.arb`
  приложения, когда они там есть.
- **Минимальный возраст пользователей — 16+.**
- **Аналитика:** GA4 и Яндекс Метрика (новые ресурсы), только после согласия в баннере, вебвизор выключен —
  как в образце.
- **Обратная связь:** форма → Edge Function `contact` в Supabase **Karmanto** (`dmdlrsdhxakjyhuadbtc`) → таблица +
  уведомление в **отдельный** Telegram-бот Karmanto. Функция делается в репозитории приложения (`docs/app-tasks.md`).
- **Не входит:** блог; цены, Pro и лимиты; отдельная страница-инструкция по импорту (только FAQ); веб-версия
  приложения; автоперенаправление по языку; детальные категории cookies; капча; отзывы и рейтинги из сторов;
  полный пакет логотипа (PDF/JPG) в брендбуке.
