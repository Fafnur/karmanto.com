## 2026-10-28 — grill задачи 6

- **Порядок задач:** задача 6 — раньше 4 и 5. Задача 4 ждёт K.2 (функцию `contact`) в репозитории приложения,
  задача 5 — ID GA4 и Метрики.
- **Карточки первого экрана — тема «карман».** На `/` изучают испанский: _el bolsillo, recordar, siempre,
  de memoria_. На `/ru/` и `/es/` изучают английский: _pocket, remember, always, by heart_ (у английских слов есть
  транскрипция). Колоды — данные в коде (`decks.ts`), не XLF: у каждой локали свой изучаемый язык. Подписи частей
  речи — из XLF, дословно из `partOfSpeech` в `app_*.arb`. «Знаю» / «Не знаю» активны и до переворота, как
  в приложении; после последней карточки снова первая.
- **Названия режимов:** в `app_*.arb` есть только подписи кнопок, поэтому заголовки такие: Study / Review learned /
  Writing, Изучение / Повторение выученного / Письмо, Estudio / Repaso de aprendidas / Escritura.
- **Без названия Anki:** «Two answers instead of four grades» — без сравнения с конкурентом.
- **Якорь `FRAGMENTS.googleSheet`** (`/support/#google-sheet`) заведён в задаче 6. В задаче 4 этот `id` получит
  вопрос FAQ про Google Таблицу.
- **Вопросы короткого FAQ** (`Support FAQ|…`) на главной — те же строки, что будут на `/support/`: один перевод
  на обе страницы.
- **`@karmanto/ui/store-buttons` — пока без аналитики.** Событие `store_click` добавится в задаче 5.
- **Тексты главной — черновик агента.** Владелец поправит их, когда будет финальная версия приложения.

## 2026-10-27 — исходный grill me (до плана)

Контекст: сайт для приложения Karmanto делается по образцу `isomantika.com` — те же страницы, стек, сборка и
деплой; меняются бренд, цвета, шрифт и тексты.

- **Новый репозиторий с чистой историей**, а не копия образца: код переносится поэтапно, сущности Nx — генераторами.
  Задачи крупные (7 вместо ~12 у образца): одна задача — один PR, внутри коммиты по шагам.
- **Домены:** `karmanto.com` — основной; `karmanto.ru` (и `www` обоих) — 301 на `https://karmanto.com$request_uri`
  (в корень, не на `/ru/`: язык человек выбирает сам).
- **Тема по умолчанию — системная** (как в приложении), а не тёмная, как у образца. Переключатель — как в образце.
- **Шрифт — только Noto Sans**, как в приложении (у образца — пара Cormorant Garamond + Manrope).
- **Про цену на сайте — ничего:** ни «бесплатно», ни «скоро Pro». **Лимиты** (10 000 слов, 10 списков) тоже нигде
  не упоминаются. Pro-функции не описываются (в v1 приложения они скрыты).
- **Юридические тексты — черновик агента** по образцу текстов Isomantika, адаптированный под данные Karmanto; владелец
  вычитывает и показывает юристу. Только в задаче 3 — дальше правило образца: тексты без просьбы не трогать.
- **Минимальный возраст — 16+** (у образца 18+ из-за таро): возраст самостоятельного согласия по GDPR в большинстве
  стран ЕС; в Google Play — аудитория без детей, без Families Policy.
- **Первый экран главной — карточка-бумажка в рамке телефона**, сделанная вёрсткой, с переворотом и кнопками
  «Знаю» / «Не знаю» (аналог расклада из настоящих карт у образца). Скриншоты и видео — после выпуска приложения.
- **Факты для текстов — из `docs/plan.md` приложения (v1)**, хотя учёба, импорт и напоминания ещё не сделаны;
  перед выпуском — сверка с приложением (задача 7).
- **Аналитика — GA4 и Метрика, новые ресурсы**, как в образце: только после согласия.
- **Форма обратной связи** → функция `contact` в Supabase Karmanto → **отдельный Telegram-бот Karmanto**
  (не общий с Isomantika).
- **Разделы главной сверх базовых:** режимы учёбы, импорт, языки, офлайн и синхронизация.
- **Импорт из Google Таблицы объясняется вопросом в FAQ поддержки**, отдельной страницы нет.
- **Бренд:** иконка приложения как есть (шапка, фавикон, иконки, `og.png`) + вордмарк «Karmanto»; мини-брендбук
  (`brandbook/README.md`) без пакета PDF/JPG.

  цветовых классов Tailwind (2), подмножества шрифта с `latin-ext`, `greek`, `vietnamese` (2), список вопросов FAQ (4),
  темы формы как у образца (4), пары слов на карточке первого экрана (6).
